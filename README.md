# Value Calculator

A simple and professional calculator web application built using **HTML, CSS, and JavaScript**.

This application allows users to enter a number and perform different mathematical operations using buttons.

## Features

- **Square:** Calculates the square of the entered number.
- **Half:** Calculates half of the entered number.
- **Percentage:** Calculates what percentage the first value is of the second value.
- **Circle Area:** Calculates the area of a circle using the entered value as the radius.
- **Input Validation:** Checks whether the entered values are valid.
- **Responsive Design:** Works on desktop and mobile screens.
- **Professional UI:** Clean design with styled input fields and buttons.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone this repository or download the project files.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a number in the input field.
5. Click the button for the operation you want to perform.
6. View the result displayed on the screen.

No additional software or installation is required.

## How to Use

### 1. Square

Enter a number and click the **Square** button.

**Example:**

Input: `5`

Output: `25`

### 2. Half

Enter a number and click the **Half** button.

**Example:**

Input: `10`

Output: `5`

### 3. Percentage

1. Enter the first value.
2. Click the **Percentage** button.
3. Enter the second value in the additional input field.
4. Click **Calculate Percentage**.

**Example:**

First Value: `20`

Second Value: `200`

Output: `20 is 10% of 200`

### 4. Circle Area

Enter the radius of a circle and click the **Circle Area** button.

The application uses the following formula:

`Area = π × radius × radius`

**Example:**

Radius: `7`

Output: `Circle Area = 153.94`

## Input Validation

The application includes basic input validation to handle:

- Empty input fields.
- Invalid numeric values.
- A zero denominator when calculating percentages.
- Negative radius values for circle area calculations.
